3. 请比较 src-dst-ip 与 src-dst-mac 的负载均衡方式，请详细论述
    **src-dst-ip**:源 MAC + 目的 MAC进行hash，防止单一字段，流量全从一条链路上走
    
    **src-dst-mac**:源 IP + 目的 IP进行hash，成员链路更加均衡
