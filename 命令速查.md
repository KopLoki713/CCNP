# 远程登录
### telnet 配置 
```python
enable secret cisco123    # 特权模式密码（加密存储）
line vty 0 4
password cisco          # VTY 登录密码                 
login           # 开启密码检测
transport input telnet  # 允许 Telnet
```

### ssh配置 
```

hostname R1
ip domain-name cisco.com                  
crypto key generate rsa                   
1024
ip ssh version 2                          
line vty 0 4
login local                              
! SSH 需要域名生成密钥
! 生成 RSA 密钥
! 强制使用 SSH v2（v1 有已知漏洞）
username admin privilege 15 secret cisco123   ! 创建本地用户
! 使用本地用户认证
transport input ssh                      
! 只允许 SSH
```

# 交换
## DTP
```
dtp
switchport mode dynamic desirable
switchport mode dynamic auto
```
被动等待对端协商。
对端为 
trunk 或 
dynamic desirable 时，通常会形成 Trunk。
两端都是 
dynamic auto 时，双方都不主动，通常不会形成 Trunk。

## vtp
### VTP v3
```
#SW1 — 主服务器
SW1(config)# vtp domain LAB
SW1(config)# vtp version 3
SW1(config)# vtp password Cisco123
SW1(config)# vtp mode server
SW1(config)# vtp primary vlan

SW2 / SW3 — 客户端
SW2(config)# vtp domain LAB
SW2(config)# vtp version 3
SW2(config)# vtp password Cisco123
SW2(config)# vtp mode client

# 其他常用命令

Switch(config)# vtp traps generation     ! 开启 VTP 告警
Switch(config)# no vtp                   ! 关闭 VTP
Switch(config)# vtp mode off             ! v3：彻底不参与

Switch(config)# vtp mode transparent     ！本地管理 VLAN，只转发 VTP 报文，不参与同步
```



## EtherChannel 链路聚合

### 二层聚合
```
interface range gigabitEthernet 1/0/23 - 24
description To-SW2-EtherChannel
switchport
channel-group 1 mode active
no shutdown


interface port-channel 1
description To-SW2
switchport mode trunk
switchport trunk allowed vlan 10,20
switchport trunk native vlan 999
```

### 三层聚合

```
interface range gigabitEthernet 1/0/47 - 48
description L3-EtherChannel-To-SW2
no switchport
no ip address
channel-group 10 mode active
no shutdown


interface port-channel 10
description L3-To-SW2
no switchport
ip address 10.0.12.1 255.255.255.252
no shutdow
```

# ACL和nat

## acl
###标准acl
```
命名式（推荐，可增删改）
Router(config)# ip access-list standard SALES_IN
Router(config-std-nacl)# permit 192.168.10.0 0.0.0.255
Router(config-std-nacl)# deny   any log
Router(config-std-nacl)# permit any
Router(config-std-nacl)# exit

应用到接口
! 接口方向
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip access-group 10 in          ! in | out

```
### 拓展acl

```
access-list <100-199|2000-2699> {permit|deny} <协议>
    <源> [通配符] [运算符 端口]
    <目的> [通配符] [运算符 端口]
    [established] [log] [time-range <名字>]

Router(config)# ip access-list extended WEB_FILTER
Router(config-ext-nacl)# permit tcp 192.168.10.0 0.0.0.255 any eq 80
Router(config-ext-nacl)# permit tcp 192.168.10.0 0.0.0.255 any eq 443
Router(config-ext-nacl)# permit icmp any any echo
Router(config-ext-nacl)# deny   ip any any log
Router(config-ext-nacl)# exit

应用到接口
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip access-group WEB_FILTER 
```
### 其他
```
查看
Router# show access-lists
Router# show ip access-lists
Router# show ip access-lists WEB_FILTER
Router# show ip interface GigabitEthernet0/1        ! 看接口挂了哪些 ACL
Router# show run | section access-list


命名 ACL 的序号编辑
Router(config)# ip access-list extended WEB_FILTER
Router(config-ext-nacl)# 15 permit tcp 10.0.0.0 0.0.0.255 any eq 22   ! 插到第 15 行
Router(config-ext-nacl)# no 20 

重新编号（整理间距）
Router(config)# ip access-list resequence WEB_FILTER 10 10

计数与清空
Router# show access-lists                 ! 每行有 (matches) 计数
Router# clear access-list counters 100
Router# clear ip access-list counters WEB_FILTER
```

**标准 ACL：挂在 (B) 侧靠近目的**
**扩展 ACL：挂在 (A) 侧靠近源**


## NAT

先定义 inside/outside，再配路由
```
! 定义内网接口
interface g0/0
ip nat inside   
! 定义外网接口                       
interface g0/1
ip nat outside                         


ip route 0.0.0.0 0.0.0.0 202.100.1.1    
! 默认路由，保证出方向有路
```

###  静态 NAT  (1 对 1)
一个私网 IP 固定映射一个公网 IP。适合内网服务器对外发布，但不节约公网 IP，实际不使用
```
ip nat inside source static 192.168.10.100 202.100.1.3
show ip nat translations    
! 查看静态映射关系
```

### 动态 NAT（地址池）
```
ip nat pool PUBLIC 202.100.1.5 202.100.1.7 netmask 255.255.255.0
ip access-list standard NAT
permit 192.168.10.0 0.0.0.255           
! 选出哪些内网流量要做 NAT
ip nat inside source list NAT pool PUBLI

show ip nat translations    
! 查看动态转换记录
```

### PAT（Port Address Translation，端口地址转换
```
ip access-list standard NAT
permit 192.168.10.0 0.0.0.255           
! 选出哪些内网流量要做 NAT
ip nat inside source list NAT interface g0/1 overload   ! 启用 PAT
```
